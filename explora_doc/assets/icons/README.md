# Icons Directory

This directory should contain the following icon files for the ExploraDoc application:

## Required Icons

### Core Application Icons
- `app_icon.png` - Main application icon (256x256 recommended)
- `app_icon.ico` - Windows application icon (multi-size .ico file)

### UI Button Icons (20x20 or 24x24 recommended)
- `folder.png` - Folder icon for "Change Folder" button
- `start.png` - Play/start icon for "Start Test" button  
- `stop.png` - Stop icon for "Stop Test" button
- `export.png` - Export/document icon for "Export" button
- `clear.png` - Delete/trash icon for "Clear" button

## Icon Guidelines

- **Format**: PNG with transparent background
- **Size**: 20x20 or 24x24 pixels for button icons, 256x256 for app icon
- **Style**: Clean, modern icons that work in both light and dark themes
- **Colors**: Monochrome or subtle colors that match the app's theme

## Where to Find Icons

You can get suitable icons from:
- **Heroicons**: https://heroicons.com/ (free, clean icons)
- **Lucide**: https://lucide.dev/ (free, consistent icon set)
- **Tabler Icons**: https://tabler-icons.io/ (free, outline style)
- **Feather Icons**: https://feathericons.com/ (free, minimal)

## Usage

Once you place icon files in this directory, the application will automatically use them instead of emoji characters in the buttons.
